# 晚间护肤流程

## 标准步骤顺序

晚间护肤遵循"先水后油、由稀到稠"的原则：

1. 卸妆（仅化了妆或涂了防晒时需要）
2. 洁面（氨基酸洁面，水温 32℃ 左右）
3. 化妆水 / 爽肤水
4. 精华（功效成分在这一层：美白、抗老、修护）
5. 乳液 / 面霜（锁水封闭）
6. 面油（干皮可选，放在最后一步）

## 功效成分的使用时机

- **视黄醇（A 醇）**：晚间使用，从低浓度（0.1%）开始，每周 2~3 次逐步建立耐受；
  使用期间白天必须严格防晒。
- **果酸 / 水杨酸**：晚间使用，刷酸当晚不再叠加 A 醇，两者错晚交替。
- **维 C 精华**：传统建议白天用（协同防晒抗氧化），高浓度原型 VC 晚上用也可以。
- **玻尿酸**：任何时间可用，注意在湿润的皮肤上涂，之后用面霜封闭，否则可能倒拔干。

## 屏障受损期间的精简护肤

当皮肤出现泛红、刺痛、脱皮时，暂停所有功效型产品，只保留三步：
温和清洁 → 保湿修护（含神经酰胺、B5）→ 物理防晒。
一般 1~2 周屏障可自行修复，期间避免热水洗脸与去角质。
