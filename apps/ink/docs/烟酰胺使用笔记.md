# 烟酰胺使用笔记

## 基本信息

烟酰胺（Niacinamide，维生素 B3）是护肤品中最经典的成分之一，主打美白提亮与控油。

## 浓度选择

- 新手入门建议从 **2%~3%** 浓度开始，建立耐受后再逐步提高。
- 主流有效浓度为 **4%~5%**，市面常见产品（如 The Ordinary 烟酰胺 10% + 锌）浓度偏高，适合耐受皮。
- 浓度并非越高越好：超过 5% 之后边际收益递减，刺激性反而上升。

## 使用注意事项

1. 烟酰胺与酸类（果酸 / 水杨酸）可以叠加，但敏感肌建议错开早晚使用。
2. 部分人使用高浓度烟酰胺会出现泛红、刺痛，这是"烟酰胺不耐受"，通常 1~2 周可建立耐受。
3. 白天夜晚均可使用，白天使用有助于增强皮肤屏障、减少紫外线诱导的色素转运。
4. 与视黄醇（A 醇）叠加时建议先建立各自耐受，再同场使用。

## 常见搭配

- 烟酰胺 + 锌：控油组合，适合油皮。
- 烟酰胺 + 玻尿酸：保湿 + 屏障修护，适合干皮。
- 烟酰胺 + 维 C：有观点认为高浓度下会相互抵消，实际正常浓度下可以同用，敏感肌可分早晚。

## 保存与保质期

避光密封保存，开封后建议 12 个月内用完；若出现变色、异味或分层，
说明成分已氧化失效，应停止使用。
